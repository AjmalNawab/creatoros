# Research fact sheet

1. Start from the chosen **angle and audience** in the prompt (from the selected idea). Every fact should serve that angle.
2. Collect 8–12 facts. Prefer USGS, NASA, ESA, NOAA, WHO, Smithsonian, Britannica, National Geographic, the Met Office and peer-reviewed reviews. Use WebSearch to verify anything recent or numeric; don't rely on memory for numbers, dates or records.
3. Confidence:
   - **high:** stated by an authoritative source.
   - **medium:** widely reported, or rounded.
   - **low:** needs checking. Low-confidence facts must not reach the script.
4. **Pakistan angle:** include one only if it is real and verifiable (a place, an event, a scientist, a season). Never invent one.
5. `sources` must be real URLs you actually used. `avoid` lists common misconceptions and sensational framings for this topic.
6. Keep each fact one sentence, plain English. The script agent translates.
